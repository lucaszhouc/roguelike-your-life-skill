# Quality Checklist

## Analysis

- [ ] Current state is grounded in evidence.
- [ ] Existing assets are separated from unproven potential.
- [ ] Recent runs are based on real events when evidence exists.
- [ ] Bosses are state-transition milestones, not routine tasks.
- [ ] Failure drops contain real portable value.
- [ ] The report avoids forced positivity.
- [ ] The report does not quietly turn into advice unless the user asked for strategy.

## Visual

- [ ] Main title is `ROGUELIKE YOUR LIFE`.
- [ ] All public-facing copy is English.
- [ ] Top panel uses sections 1–5.
- [ ] Bottom panel uses sections 6–11.
- [ ] Section 6 is not duplicated.
- [ ] Mythic Hades-inspired energy is the primary direction.
- [ ] Mobile rhythm is roughly 1–1.5 major modules per viewport.
- [ ] The protagonist remains visually consistent across panels.
- [ ] Palette and border language remain consistent.
- [ ] The map is a major section, not a tiny decoration.
- [ ] Boss cards are visually distinctive.
- [ ] Meta Progress creates the closing climax.

## Public release privacy

- [ ] Examples are fictional or anonymized.
- [ ] No real names, handles, private company or project affiliations, exact locations, financial figures, identifying dates, private achievements, or private conversation screenshots are included.
- [ ] No official game screenshots, logos, proprietary fonts, or copyrighted game assets are bundled.
- [ ] README explains the workflow in under two minutes.
