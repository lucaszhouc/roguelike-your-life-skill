# Visual Style Pack

The goal is not to copy any existing game screen. Build a consistent **mythic underworld action-roguelike report UI** using original generated assets.

## Visual keywords

- mythic underworld
- heroic portrait
- black stone
- crimson flame
- warm gold
- laurel wreath
- temple architecture
- floating arenas
- sharp inked silhouettes
- cinematic panel framing
- high contrast
- readable game UI
- dramatic but not horror-dominant

## Palette

- Obsidian: `#0A0C0D`
- Charcoal: `#15191B`
- Crimson: `#C8342F`
- Ember: `#F05A32`
- Warm Gold: `#D9A441`
- Pale Gold: `#F2D48A`
- Parchment: `#EAD9B4`
- Spectral Teal: `#48B8A8`
- Deep Cyan: `#2D6D7D`

## Component language

- **Section headers:** dark band, warm-gold frame, oversized number badge
- **Protagonist:** large half-body or 3/4 portrait, heroic silhouette, red fabric or laurel accents
- **Stats:** segmented red / gold bars
- **Relics:** dark cards, luminous icon, gold frame
- **Debuffs:** red-black hazard cards, flatter and more aggressive symbols
- **Map:** floating terrain, route nodes, distinct color zones
- **Boss cards:** character or deity-like portraits, not only monsters
- **Meta Progress:** oracle / parchment panel, major progress bar, compact +1 markers

## Typography feel

Use a dramatic serif display face for major headings and a clean, highly legible serif or sans-serif for body text. Do not distribute proprietary game fonts.

## Illustration rules

- strong silhouettes
- controlled ink-like edges
- cinematic value contrast
- glowing environmental accents
- elegant rather than grotesque
- every decorative element should support hierarchy

## Optional darker texture

Only add heavier distressed dungeon texture to:

- Debuffs
- Failure Drops
- battle-log edges
- environmental framing

Do not let the darker layer take over the full composition.
