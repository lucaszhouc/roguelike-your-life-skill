# Content Model

## Core state vector

Represent the user's current state as:

`S = {skills, experience, tools, projects, resources, relationships, trust, users, constraints, active paths}`

Each run is:

`choice → action → exposure to reality → feedback → settlement`

After settlement:

`S(n+1) = S(n) + ΔS`

`ΔS` may be positive, negative, or close to zero. Failure does not automatically equal growth.

## Boss test

A milestone behaves like a boss when it satisfies at least two of the following:

- clearing it materially changes the opportunity set of later runs
- it creates new trust, users, revenue, team capacity, or distribution
- it proves a previously unproven loop
- it unlocks a higher-level map or opponent class
- it materially reduces the cost of future attempts in the same category

## Run settlement types

- **Information Drop** — rules discovered, routes eliminated, hypotheses updated
- **Skill Drop** — new skill or improved execution fluency
- **Asset Drop** — code, model, content, audience, user base, process, or reusable artifact
- **Trust Drop** — external recognition, reputation, or relationship gains
- **Resource Drop** — money, time, distribution, equipment, or access
- **No Drop** — almost no portable value

## Confidence labels

For non-explicit judgments, optionally use:

- **High** — repeated behavior or results support the claim
- **Medium** — recent evidence supports it, but the sample is limited
- **Low** — tentative inference from sparse signals
