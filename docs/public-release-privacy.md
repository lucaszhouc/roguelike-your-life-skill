# Public Release Privacy

Before publishing this skill pack, public examples must be fictional or anonymized.

Do not include:

- real names or personal account handles
- a user's employer, target company, school, or private organization affiliation
- real project names tied to a specific user
- precise location
- financial balances, income, budget, subscription amounts, or private spending
- exact personal dates or timelines that make the user identifiable
- private achievements, rankings, application status, or job-search counts
- screenshots or excerpts from private conversations
- private contact information, credentials, API keys, or authentication material

Generic categories such as `job search`, `side project`, `social distribution`, `resource constraint`, `skill growth`, or `networking` are acceptable when they are not tied to an identifiable person.

When in doubt, abstract the detail or omit it.
