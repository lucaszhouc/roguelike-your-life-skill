# Security Policy

## Reporting a vulnerability

Please do not open a public issue for a security problem. Email `lucaszhouc@gmail.com` with the subject `[SECURITY] Roguelike Your Life` and include only the minimum reproduction details needed to investigate it.

This is a single-maintainer project, so responses are best effort and have no guaranteed service level.

## Scope

Report vulnerabilities in this repository's skill instructions, tools, schemas, or bundled assets. Vulnerabilities in the AI product or model that runs the skill should be reported to that product's security channel.

## Privacy

Please remove personal identifiers, private conversation excerpts, credentials, and other sensitive material from reports whenever possible.
