# Image Prompt — Bottom Panel (1:3)

Generate the **bottom half** of a 1:6 vertical Roguelike Your Life report. It must continue seamlessly from the previously generated top panel.

## Continuity requirements

Match the top panel's:

- protagonist
- crimson / black / gold / teal palette
- border system
- icon language
- typography feel
- illustration rendering style

## Sections

Start at 6 and generate only:

6. Map of Active Runs
7. Path Breakdown
8. Boss Encounters
9. Recent Run Log
10. Failure Drops
11. Meta Progress

## Rules

- **Section 6 appears exactly once and only at the beginning of this panel.**
- The map should be one of the largest visual sections, using floating underworld terrain, temple nodes, routes, and color-coded regions.
- Bosses should use powerful character-card compositions, not only monsters.
- Recent Run Log should feel like an authentic run history.
- Failure Drops may use stronger red-black styling while remaining inside the same mythic visual system.
- Meta Progress is the final climax: large progress bar, portable gains, protagonist return, and a strong closing scene.
- End with: `ANOTHER RUN. A BETTER YOU.`
